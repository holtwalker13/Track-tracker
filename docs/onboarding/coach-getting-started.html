Coach Getting Started

Your first week: KPIs, programs, and live testing

Track Tracker helps you measure performance in class, compare athletes, improve with progress charts and workout logs, and compete on leaderboards. Your school administrator verifies roster and classes before you begin; this guide covers coach workflows on day one.

1. Sign in and learn the layout

  1. Open your school’s Track Tracker URL and sign in with the email and password from your welcome message (or complete the invite link if this is your first login).
  2. Use the top navigation: School Programs KPIs Compete
  3. On most coach screens, use the class scope bar to pick yourself (if you coach multiple classes) and the class/period you are working with. Many actions apply to the selected class only.
  4. Under School, skim Roster, Classes, and your class enrollments so you recognize your students before testing or assigning workouts.

2. Build your first KPI set

KPIs are the metrics you test and track (sprints, jumps, strength standards, and custom school activities). Medal targets (Gold / Silver / Bronze) drive leaderboards and student goals.

  1. Go to KPIs in the top nav.
  2. If you need a new pack, click New set, name it (e.g., “Track & Field — Fall”), and choose the sport context.
  3. Add metrics from the school KPI library. Mark important tests as ranked (they appear first when you create a test and on leaderboards). Others can stay unranked for tracking only.
  4. Tap a metric to set Gold, Silver, and Bronze targets for each age/gender band you use.
  5. Click Save KPI set. Optionally duplicate a public set from another coach at your school to save time.
  6. Link the set to your class if your school uses class-scoped KPIs (your admin or lead coach may have already done this).
Strength / weight room: Custom lifts live under Programs → School lift library → Build lift. Those lifts can also appear in KPI targets and testing presets for weightlifting classes.

3. Build your first workout program

Programs are daily training templates (sets, reps, and lifts) you assign to a class on the calendar.

  1. Go to Programs. The week view shows scheduled workouts and testing days for your selected class.
  2. Open the program builder (create a new template). Name the program (e.g., “Week 1 — Intro strength”).
  3. Select lifts from your school’s lift library and configure sets/reps (use the set builder grid for per-set detail).
  4. Save the template, then assign it: choose the template, class, and date. Students see the workout under Log workout on their devices.
  5. Optional: use Auto-generate block for a multi-week linear plan (e.g., 5×5 with a deload week) instead of building each day by hand.
  6. Review completion under Programs → Workout logs or export CSV for your records.

4. Administer a live test

Testing sessions capture official marks, attempts, PRs, and absences for a class on a given date.

  1. From Programs, select the class and date, then click Create test.
  2. In New live testing session, pick the class, test date, and session name. Ranked KPIs from the class’s KPI set are pre-selected; add or remove events as needed.
  3. Start the session to open the live testing grid. Enter marks attempt-by-attempt for each student and activity. The grid saves progress as you go.
  4. For large groups or station work, open Student station mode so athletes enter their own attempts on phones (you stay in control of the session).
  5. Mark students absent, injured, or DNP when applicable so reports stay accurate.
  6. When finished, review results from the session page or student profiles under School → Roster.
Weight room classes: Sessions for classes named like “Weights” may pre-select strength events—adjust before starting if you are running a mixed test day.

5. Day-one tasks checklist

  • Compete → Leaderboards: Preview how ranks look for your class; confirm privacy settings meet school policy.
  • Compete → Compare: Line up head-to-head views before parent meetings or team meetings.
  • KPIs → Import marks: Upload CSV historical data if your admin provided a file from prior seasons.
  • School → Roster: Add late enrollments or issue student login invites when your school allows self-sign-up.
  • Programs: Schedule the first week of workouts or your first testing session so students see activity on login.

6. Getting help

Contact your athletic director or Track Tracker onboarding lead for roster fixes, new coach accounts, or school-wide settings. For in-app behavior, note the class you had selected and the screen URL when reporting an issue.
